# 予約管理＆レシート印刷システム (V3 - 認証対応版)

エプソン製サーマルプリンター『TM-T88Ⅶ (80mmロール紙)』での印刷に特化した、完全ブラウザ完結型の予約管理システムです。
サーバーやデータベースの構築は一切不要で、HTMLファイルをブラウザで開くだけですぐに使用開始できます。

## 🚀 使い方
1. `index.html`、`styles.css`、`app.js` を同じフォルダに配置します。
2. `index.html` をブラウザ（Google ChromeやEdgeなど）で開きます。
3. 初回起動時はログイン画面が表示されます。

## 🔐 ログイン機能について
本システムは簡易的なセキュリティとして、ログインシステムを搭載しています。

* **初期ログインID:** `admin`
* **初期パスワード:** `admin`

ログイン後、画面上部の「🔒 セキュリティ・アカウント設定」から、新しいIDとパスワードに変更することができます。

### ⚠️ セキュリティに関する重要事項
このシステムはサーバー通信を行わず、データやパスワードはすべて「使用している端末（ブラウザ）」の中に保存されます。
そのため、以下の点にご注意ください。

1. 端末をまたいでのデータ同期はされません（iPadで変更したパスワードは、PC版には反映されません）。
2. ブラウザの履歴やキャッシュを完全に削除すると、パスワードと保存された予約データがリセットされます。
3. 専門的な知識を持つ人がブラウザのデベロッパーツールを使用すると、突破される可能性があるため、あくまで「覗き見・誤操作防止用」の鍵として運用してください。

## 🖨️ 印刷設定のコツ
* 印刷サイズは「80mm幅・縦100mm」に完璧に収まるように設計されています。
* 印刷プレビュー画面で、**「ヘッダーとフッターを印刷する」のチェックを外す**と、URLや日付などが印字されず綺麗に出力されます。
* 余白設定は「最小」または「なし」を推奨します。
