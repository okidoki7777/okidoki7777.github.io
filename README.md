# Luminous Reservation Manager (予約管理システム)

大人のエンターテインメント店舗向けに設計された、直感的でプレミアムなデザインの予約管理システムです。
インストールやサーバーの環境構築を必要とせず、ブラウザだけで安全・快適に動作します。

---

## 🚀 起動方法

1. `reservation-manager` フォルダ内の **`index.html`** ファイルをダブルクリックします。
2. お使いのWebブラウザ（Chrome, Edge, Safariなど）でシステムが即座に起動します。

*※データはブラウザの `localStorage`（ローカルストレージ）に自動保存されるため、ブラウザを閉じたりページを再読み込みしたりしてもデータが消えることはありません。*

---

## ✨ 主な機能

### 1. 予約の追加と編集
- 画面左側のフォームから「日付」「開始時間」「お客様名」「電話番号」「女の子の名前」「コース時間」を入力して登録できます。
- 登録した予約は、一覧表の「編集」ボタンを押すことで、フォームにデータを呼び出して内容を変更することができます。

### 2. 料金の自動計算（項目⑦）
- 「コース時間」を選択すると、設定された基本料金が自動的に算出されます。
- カスタム時間を入力することも可能です（1分あたりの料金設定に基づき自動計算されます）。

### 3. 料金の調整システム（項目⑧）
- 交通費（加算項目）や割引（減算項目）を入力すると、自動計算された基本料金にリアルタイムで反映され、「お支払総額」が自動で算出されます。
- 調整の理由（例：「送迎代」「WEB限定割引」など）をメモとして残すことができます。

### 4. コース料金プラン設定
- 画面上部の「料金システム設定」ボタンをクリックすると、設定画面（モダール）が開きます。
- 各コース（60分、90分、120分、150分、180分）の基本料金や、カスタム時間の1分あたり単価を自由に変更し、保存することができます。

### 5. CSVファイル出力
- 「CSVダウンロード」ボタンを押すと、表示中の予約一覧をCSVファイルとして保存できます。
- **文字化け対策（BOM付きUTF-8）**が施されているため、Excelでダブルクリックしても日本語が文字化けすることなく開くことができます。

### 6. プリンターでの印刷
- 「印刷する」ボタンを押すと、ブラウザの印刷ダイアログが開きます。
- 印刷用に最適化されたレイアウト（A4横向きに最適化）になっており、**入力フォームや操作用ボタンなどの不要なGUI要素は自動的に非表示**になり、美しい予約台帳テーブルのみが紙に印刷されます。

## 🛠️ 技術仕様

- **構造(Structure)**: HTML5
- **スタイル(Styling)**: CSS3 (Glassmorphism, CSS変数, `@media print` 印刷定義)
- **ロジック(Logic)**: Vanilla JavaScript (ES6)
- **データ保存**: Web Storage API (localStorage)
- **フォント**: Outfit (欧文) / Noto Sans JP (日本語)
